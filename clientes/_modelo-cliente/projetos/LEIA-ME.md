# Projetos deste cliente

Uma pasta por projeto, nomeada com o identificador que o cliente usa (OS, número de projeto, nome da
máquina). Ex: `FS17146-dosagem-eixos/`.

Dentro de cada projeto, sugestão de organização:

```
[nome-do-projeto]/
  escopo.md          o que foi combinado entregar neste projeto
  cad/             arquivos e exports do CAD
  listas/            material, tags, I/Os (Excel)
  entrega/           o pacote final que vai pro cliente (PDF, ZIP)
  revisoes.md        histórico de revisão e o que mudou em cada uma
```

O padrão do que precisa existir em toda entrega está em `padroes/`.
